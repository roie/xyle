About the demo

See how Xyle works

Xyle is an open-source visual editor for the static website you already own.

This Xyle demo starts with ordinary HTML and assets. Your draft stays separate until you review it and choose to publish.

01 / The workflow

Built around reviewable changes.

The first Xyle edits happen directly in the generated website files. You do not need to move content into a separate database.

Each pending change stays visible in one ChangeSet. You can undo an edit, discard the draft, or publish the reviewed result.

Editors change content. Developers keep control of structure.

The Xyle editing boundary

02 / Shared controls

One safe path for people and agents.

Human visual editing and WebMCP use the same operations, history, safety checks, and publish boundary. Try selecting this paragraph, then use Undo or open Changes to inspect the result.

  • Edit in context.Work with the real page in a protected preview.
  • Review before publish.See useful before-and-after values for each change.
  • Keep human control.Agents can prepare edits, but they cannot publish.

03 / Your environment

Your website stays where it belongs.

Xyle runs within or beside the environment that owns the site. It is an editing integration, not a required hosting service.
